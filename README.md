Nightwick is a small, complete arena game: you are the last wick-keeper, and your lantern is the only light in a clearing of ink. Burn the moths and grubs that come for the flame, hold off the shades that light cannot touch, survive ten waves until dawn — then do it again for a better score.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```

No build step, no dependencies, no network: `game/index.html` and its ES modules play straight from any static file server (or `file://` is not enough for modules, so serve the folder).
